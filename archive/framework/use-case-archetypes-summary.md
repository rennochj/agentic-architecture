# Use Case Archetypes Summary Table

A condensed overview of the 12 GenAI use case archetypes from Part 2 with sub-cases.

| Group | Archetype | Description | Sub-Cases | Typical Outputs |
| --- | --- | --- | --- | --- |
| **A: Content & Knowledge Synthesis** | **1. Content Generation** | Create or rewrite content (text, code, images, audio, video) based on prompts, templates, or other inputs. | • Text Generation<br>• Image & Video Generation<br>• Audio & Music Generation<br>• Template & Draft Creation | Drafts, creative assets, translations, rewritten tone/style. |
| | **2. Summarization & Extraction** | Condense information or pull structured data from unstructured or semi-structured inputs. | • Text Transformation<br>• Document Analysis | Executive summaries, key-value fields from documents, named entities, timelines. |
| | **3. Grounded Q&A** | Answer questions using a specific, curated body of knowledge, providing citations and evidence. | • Question Answering<br>• Explanation & Education | Answers with source links, document snippets, and indications of what is known vs. unknown. |
| | **4. Research & Synthesis** | Produce a higher-level, analytical artifact by synthesizing information from many sources. | • Information Retrieval & Synthesis<br>• Research Assistance | Research briefs, competitive analysis reports, literature reviews, executive summaries. |
| **B: Insight & Decision Support** | **5. Data Interpretation & Analytics** | Explain trends, anomalies, and insights from structured data in natural language. | • Data Interpretation<br>• Report & Dashboard Narration | Narrative explanations of KPI changes, plain-language summaries of anomalies. |
| | **6. Recommendation & Personalization** | Tailor content, workflows, or experiences to a user, segment, or context. | • Content Personalization<br>• Recommendation Generation<br>• Learning & Skill Development | Personalized content, next-best-action suggestions, adaptive learning plans. |
| | **7. Simulation & Synthetic Data** | Generate data, scenarios, or environments for training, testing, or what-if analysis. | • Synthetic Dataset Creation<br>• Adversarial & Edge Case Testing<br>• Scenario Analysis | Synthetic datasets, adversarial test cases, catalogs of simulated scenarios. |
| **C: Process & Task Automation** | **8. Software Development Acceleration** | Assist with coding, testing, reviewing, and debugging tasks across the SDLC. | • Code Generation<br>• Code Review & Analysis<br>• Refactoring & Modernization<br>• Documentation Generation<br>• Debugging & Troubleshooting | Code diffs, unit tests, pull request summaries, refactoring suggestions. |
| | **9. Structured Workflow Automation** | Automate deterministic business processes using GenAI for specific NLP/NLG steps. | • Workflow Automation<br>• Writing Assistance | Completed forms, drafted emails for approval, reconciled records, populated CRM fields. |
| | **10. Agentic Task Automation** | Plan and execute multi-step, dynamic tasks by selecting and orchestrating tools. | • Personal Productivity Agents<br>• Interactive Task Execution<br>• Autonomous Customer Agents | A completed end-to-end task (e.g., scheduled meetings, booked trip, organized emails), along with a detailed action log. |
| | **11. Operations & Monitoring Copilot** | Assist human operators by monitoring signals, diagnosing issues, and suggesting remediation. | • Proactive System Monitoring | Incident summaries, root-cause hypotheses, remediation playbooks, status communications. |
| | **12. AI Governance & Assurance** | Use GenAI to support GRC functions like policy checks, control testing, and audit evidence gathering. | • Risk Assessment<br>• Legal & Compliance | Compliance reports, risk registers, red-teaming findings, drafts of model cards. |
